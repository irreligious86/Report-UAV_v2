# Report UAV / Звіт БПЛА

Lightweight offline-first PWA for structured UAV mission reporting from mobile devices.
Reports live in IndexedDB; optional Google Sheets sync via your own Apps Script endpoint.

Легкий офлайн-first PWA для структурованих звітів місій БПЛА з мобільних пристроїв.
Звіти в IndexedDB; опціональна синхронізація з Google Таблицями через власний Apps Script.

---

## Можливості

**Звіти:** кожен — об'єкт із полями (екіпаж, дата, борт, характер, час зльоту/ураження, MGRS-координати, боєприпас, стрім, результат), текстом, версією та статусом синхронізації.

**Зберігання:** IndexedDB (`report_uav_db_v2`) — stores: `reports`, `sync_queue`, `settings`, `sync_log`. Лічильник екіпажу та перевизначення списків — у `localStorage`.

**Журнал і KPI:** фільтр за датою/часом ураження, вкладки «Статистика» / «Журнал», KPI (вильоти, ураження, втрати, ефективність), пошук, дії на картках залежно від статусу.

**Google Sheets (опційно):** URL таблиці + URL Apps Script, режим відправки (вручну / одразу / відкладено), затримка, блокування після публікації. POST JSON на ваш endpoint.

**Черга і повтори:** офлайн або збій → звіт у черзі з backoff-ретраями (1 / 5 / 15 / 30 хв).

**Workflow після відправки:** після `sent` звичайне редагування заблоковано; «Виправити» → `resync_required` → відправити зміни.

**Карта:** маркери з `fields.coords` (MGRS→lat/lng), той самий фільтр періоду, Leaflet з вибором підкладки, fullscreen.

**Шифрований експорт/імпорт:** AES-256-GCM + PBKDF2, файл `uav_reports_v2.enc.json`, злиття за `id`. Імпорт v1-архівів зі старого застосунку підтримується.

**Нормалізація результатів:** `result-mapping.js` зводить варіанти формулювань до стандартних категорій для KPI.

**Mobile-first PWA:** темна тема, великі зони натискання, Service Worker кешує assets.

**Налаштування списків:** дрони, типи місій, боєприпаси, результати, MGRS-префікси, стріми — редактор з drag-and-drop.

**Навігація:** довге натискання на заголовок → меню екранів.

## Інструкція користувача

### Створення звіту

1. Заповніть поля форми на головному екрані. Утримання на select-полі відкриває вільний ввід. Кнопка «Зараз» вставляє поточний час.
2. **«Готово»** — створює звіт у локальній базі (унікальний id, версія 1), показує текст і копіює в буфер. Лічильник екіпажу автоматично зростає, дата оновлюється.
3. Що далі — залежить від режиму відправки в налаштуваннях: звіт лишається чернеткою, йде одразу в чергу або отримує відкладену відправку.

**Поля форми:**
- **Екіпаж** — позивний + лічильник (1–25), зберігається між сесіями
- **Дата** — автоматично синхронізується з «сьогодні»; ручний вибір не перезаписується
- **Борт** — зі списку або вільний ввід (утримати)
- **Характер** — тип місії; так само
- **Час зльоту / ураження** — вручну або «Зараз» (ГГ:ХХ)
- **Координати** — MGRS: префікс + easting (5 цифр) + northing (5 цифр)
- **Боєприпас** — зі списку або вільний ввід
- **Стрім** — посилання або «---»
- **Результат** — зі списку; формат «тип (деталі)» — для KPI враховується лише частина до дужок

### Журнал і статистика

Меню → **Журнал та статистика**. Фільтр за датою + часом ураження, кнопка «Показати».

**KPI-плитки:** вильотів, уражень, втрат, ефективність (%). **Вкладка «Статистика»:** зведення за бортами, боєприпасами, типами місій, результатами. **Вкладка «Журнал»:** картки з текстом, індикатор синхронізації, дії (копіювати, поділитися, відправити, редагувати, виправити тощо).

**Масова відправка:** кнопка «Відправити список у таблицю» ставить у чергу всі відфільтровані звіти (окрім scheduled), включно з уже sent (для повторного запису після очищення таблиці).

**Видалення:** «Видалити звіти зі списку» — лише видимі в поточному фільтрі. «Видалити всі звіти» — на екрані «Дані та інтеграція».

### Карта місій

Меню → **Карта**. Той самий фільтр періоду. Маркери за кількістю місій у точці (1 — крапка, 2–3 — зелений, 4–5 — лаймовий, 6+ — помаранчевий). Клік — картка або список місій. Перемикач підкладки внизу праворуч. Кнопка fullscreen вгорі праворуч.

### Дані, експорт, імпорт

Меню → **Дані та інтеграція**.

**Google Sheets:** URL таблиці, URL Apps Script, режим відправки, затримка, блокування. «Перевірити з'єднання» / «Зберегти».

**Експорт:** натиснути «Експорт» → ввести парольну фразу двічі → файл `uav_reports_v2.enc.json`. Пароль ніде не зберігається; без нього дані не відновити.

**Імпорт:** «Імпорт» → обрати файл → ввести пароль → звіти зливаються за `id` (файл має пріоритет). Підтримуються v2 та v1 (зі старого застосунку).

**Видалити всі звіти** — повне очищення локального архіву (з підтвердженням). Перед цим зробіть експорт.

### Налаштування списків

Меню → **Налаштування списків**. Вкладки: дрони, типи місій, боєприпаси, результати, MGRS-префікси, стріми. Drag-and-drop, додавання, видалення. Перевизначення зберігаються в `localStorage` з пріоритетом над `config.json`. Скидання до базових значень доступне.

### Google Sheets (розгортання Apps Script)

Повна інструкція: [`docs/apps-script/README.md`](docs/apps-script/README.md). Коротко:
1. У Google Apps Script створіть або відкрийте проєкт.
2. Додайте файли [`Code.gs`](docs/apps-script/Code.gs) і [`Mgrs.gs`](docs/apps-script/Mgrs.gs).
3. Deploy → Web app (Execute as: Me, Access: Anyone).
4. URL веб-додатку вставте в налаштуваннях інтеграції.

Оновлення коду: **Manage deployments → Edit → New version → Deploy** (URL не змінюється).

### Навігація

Довге натискання на заголовок **«Звіт по БПЛА»** → меню екранів.

### PWA

Android: меню (⋮) → «Встановити застосунок». iOS: «Поділитися» → «На екран "Додому"». Перший візит — з інтернетом для кешування.

### Перевірка HTML (для розробки)

```bash
npm run verify
```

## Конфігурація

Файл `config.json` містить базові списки (дрони, боєприпаси, типи місій, результати, MGRS-префікси, стріми) та defaults. Користувач може перевизначити списки через екран «Налаштування» — зміни зберігаються в `localStorage` з пріоритетом.

---

## Приватність

Звіти та черга синхронізації зберігаються локально в IndexedDB; лічильник і списки — в `localStorage`. На сервер розробника нічого не надсилається. Якщо увімкнено інтеграцію, звіти відправляються лише на **ваш** URL Apps Script. Резервна копія — зашифрований файл і пароль (без пароля дані не відновити).
